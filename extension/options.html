대기 중인 풀이

대기 0개

    실패 작업은 최대 5회 시도 후 멈춥니다. 설정을 고친 뒤 다시 저장하세요. 저장소·브랜치·폴더를 바꿔도 이전 대기 작업의 목적지는 바뀌지 않습니다.

    첫 저장 확인

    문제 페이지를 새로고침 → 코드를 제출 → 전체 통과 확인 → 확장 아이콘의 저장 결과 확인. 예제 실행은 저장되지 않습니다.

    Java 우선 지원. 일반 단일 파일 코드 문제만 지원하며, 프로그래머스 빈칸 채우기·다중 파일 문제는 제외됩니다. 사이트 구조가 바뀌면 감지 업데이트가 필요할 수 있습니다.

    토큰은 이 브라우저의 확장 전용 로컬 저장소에 보관됩니다. 사이트 페이지에는 전달하지 않으며 암호화 보관은 아닙니다. 연결 해제 시 토큰을 삭제합니다.
